# Tiare Deal Scout — Visual Standard & QC

This file is a mandatory visual gate for every client-facing Deal Scout PDF.

## Non-negotiable design language

- Tiare Travel quiet luxury / private journey editorial aesthetic.
- Image-led composition. Photography is the primary visual carrier.
- Strong full-bleed or large-format hotel/destination photography; use clean, high-resolution images without watermarks.
- Warm ivory / cream / sand / taupe / olive palette with warm graphite text and restrained gold accents.
- Elegant serif display typography paired with a clean modern sans-serif body.
- Large typography, generous whitespace, disciplined grid and consistent page rhythm.
- Client-facing language only. No internal methodology, sourcing notes, technical labels, system comments or implementation details.
- Default Deal Scout edition: concise 4-page landscape PDF unless the content clearly requires another length.

## Explicitly forbidden

- Rounded “app cards” or dashboard-like blocks as the dominant layout.
- Pastel blobs, decorative circles, cheap gradients, template ornaments or infographic gimmicks.
- Dense catalog grids, excessive badges, chips, pills or UI-style controls.
- Generic corporate presentation styling.
- Empty decorative areas that weaken the page.
- Small technical typography or long paragraphs.
- Watermarked, low-resolution, dark, dull or obviously stock-looking photography.
- Sending a PDF before rendering and visually reviewing every page.

## Deal presentation hierarchy

Every offer should communicate, in this order:
1. Destination / hotel.
2. One clear hero benefit (for example: -20%, 5=4, 3rd night complimentary).
3. Offer name.
4. Two or three concise client-relevant terms.
5. Only necessary caveats about availability / blackout dates.

Do not invent prices, discounts, availability or inclusions. Current commercial terms must be verified before publication.

## Mandatory visual QC

Before a PDF can be delivered:
- Render every page to images.
- Check every page at full size.
- Reject the output if it looks like a dashboard, cheap catalog, generic template, or internal working document.
- Reject if text clips, overlaps, becomes too small, or competes with photography.
- Reject if any photo is watermarked, visibly low-resolution or unrelated to the hotel/destination being presented.
- Reject if the cover is not visually strong enough for a premium client.
- Use the approved Tiare Travel quiet-luxury standard as the baseline, not an arbitrary default template.

If any check fails, rebuild before sending.
