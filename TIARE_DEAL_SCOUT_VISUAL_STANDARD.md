# Tiare Deal Scout — Visual Standard & QC

This file is the durable visual memory and mandatory visual gate for every client-facing Deal Scout PDF.

## Absolute cover rule — MUST NEVER BE VIOLATED

The first page must be BRIGHT, VIVID, EMOTIONAL AND SELLING.

It must use:
- one spectacular full-bleed premium destination / hotel photograph;
- strong light and attractive color; the image must create immediate travel desire;
- one uniform full-frame tonal overlay only if needed for legibility, without making the cover dull;
- Tiare Travel wordmark / brand line;
- title, date and minimal destination line.

The first page must NEVER contain:
- horizontal or vertical decorative rules/lines;
- grey lines of any kind;
- divider strokes;
- borders or frames;
- partial-width or partial-height overlay rectangles that create visible horizontal/vertical boundaries;
- bands, panels, cards, strips or boxes;
- decorative circles, pills, badges or UI elements;
- dark, flat, grey, muddy or low-energy photography.

If the cover is not immediately aspirational and commercially persuasive, or if any visible line, strip, panel edge or overlay boundary appears, the PDF MUST FAIL QC and MUST NOT be sent.

## Non-negotiable design language

- Tiare Travel quiet luxury / private journey editorial aesthetic.
- Image-led composition. Photography is the primary visual carrier.
- Strong full-bleed or large-format hotel/destination photography; use clean, high-resolution images without watermarks.
- Warm ivory / cream / sand / taupe / olive palette with warm graphite text and restrained gold accents.
- Elegant serif display typography paired with a clean modern sans-serif body.
- Large typography, generous whitespace, disciplined grid and consistent page rhythm.
- Client-facing language only. No internal methodology, sourcing notes, technical labels, system comments or implementation details.

## Mandatory Deal Scout page architecture

- Cover = 1 selling hero page.
- Every hotel special = 1 dedicated page. Never place two hotel offers on one page.
- One hotel page should normally contain:
  - one dominant hero image;
  - 1–3 secondary beautiful hotel photos where space allows;
  - hotel/destination heading;
  - concise but richer hotel description;
  - prominent offer benefit;
  - promotion / booking / stay period;
  - key confirmed conditions;
  - short Tiare View.
- The number of pages is driven by the number of worthy offers. Do not force Deal Scout into a fixed 4-page layout when more offers are selected.
- Airfare specials may receive one dedicated page each or a clearly separated airfare section, provided the same premium visual standard is maintained.

## Explicitly forbidden

- Two unrelated hotels compressed onto a single page.
- Rounded “app cards” or dashboard-like blocks as the dominant layout.
- Pastel blobs, decorative circles, cheap gradients, template ornaments or infographic gimmicks.
- Dense catalog grids, excessive badges, chips, pills or UI-style controls.
- Generic corporate presentation styling.
- Empty decorative areas that weaken the page.
- Small technical typography or long paragraphs.
- Watermarked, low-resolution, dark, dull or obviously stock-looking photography.
- Sending a PDF before rendering and visually reviewing every page.
- Reintroducing a previously rejected visual element after the user has explicitly banned it.

## Deal presentation hierarchy

Every hotel offer should communicate, in this order:
1. Destination / hotel.
2. Why this hotel is special.
3. One clear hero benefit (for example: -20%, 5=4, 3rd night complimentary).
4. Exact promotion / booking / stay period when stated by the source.
5. Key client-relevant terms.
6. Tiare View.
7. Only necessary caveats about availability / blackout dates.

Every airfare offer should communicate:
1. Route.
2. Airline and cabin.
3. Fare / saving.
4. Booking deadline.
5. Travel period.
6. Key restrictions.
7. Why the fare is relevant for a Tiare client.

Do not invent prices, discounts, availability, periods or inclusions. Current commercial terms must be verified before publication.

## Mandatory visual QC

Before a PDF can be delivered:
- Render every page to images.
- Check every page at full size.
- Inspect the cover specifically for brightness, color, emotional impact, sales appeal and any unintended line, strip, panel edge, overlay boundary, border or frame.
- Confirm that every hotel special has its own dedicated page.
- Confirm that each hotel page contains meaningful hotel context and beautiful photography, not just promo mechanics.
- Confirm that promotion periods are shown when supported by source data.
- Reject the output if it looks like a dashboard, cheap catalog, generic template, or internal working document.
- Reject if text clips, overlaps, becomes too small, or competes with photography.
- Reject if any photo is watermarked, visibly low-resolution or unrelated to the hotel/destination being presented.
- Reject if the cover is not visually strong enough for a premium client.
- Use the approved Tiare Travel quiet-luxury selling standard as the baseline, not an arbitrary default template.

If any check fails, rebuild before sending.
