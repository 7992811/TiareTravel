# Tiare Travel Agent Memory

Mandatory permanent rules for all Tiare Travel client-facing PDF work and all Tiare Deal Scout outputs.

## Cover memory
1. The first slide MUST be bright, vivid, emotional and selling. It should create immediate desire to travel.
2. Use a spectacular, high-quality full-bleed destination or hotel photograph with strong light, color, water/sky/landscape or architecture where relevant.
3. The cover is full-bleed premium photography + elegant Tiare Travel typography only.
4. Never add decorative horizontal/vertical lines on the first page.
5. Never add grey lines.
6. Never add divider strokes, frames, borders, strips, panels or cards on the first page.
7. Never use partial overlay rectangles that create a visible edge/boundary across the cover.
8. If contrast is needed, use one uniform full-frame tonal overlay only and keep the photograph bright and vivid.
9. The cover must be visually checked specifically for brightness, emotional appeal and sales impact before delivery.
10. Any reappearance of a previously rejected cover line or a dull/grey/flat cover is a QC failure and the file must be rebuilt before delivery.

## Tiare visual memory
- Quiet luxury, editorial, premium, image-led.
- The visual goal is not merely elegant minimalism: every client-facing presentation must be aspirational and commercially persuasive.
- No dashboard aesthetics, cheap cards, circles, UI chips, generic corporate layouts or technical-looking graphics.
- Bright, refined, high-quality hotel/destination photography; no watermarks.
- Large elegant typography, restrained copy, generous whitespace.
- Client-facing output only; no technical methodology or internal notes.
- Every PDF must be rendered and visually inspected before delivery.

## Deal Scout offer-page memory
- Every selected hotel offer gets ONE dedicated full page. Do not place two different hotel offers on the same page.
- Each hotel page must include:
  1. destination / hotel name and category;
  2. 2–4 beautiful, relevant hotel photographs whenever the page composition allows it, with at least one dominant image;
  3. a richer client-oriented description of the hotel: location, atmosphere, defining features, beach / island / city context, rooms or villas, gastronomy, family/adults positioning, notable experiences and who the hotel suits;
  4. the special-offer mechanic and the client benefit highlighted clearly;
  5. the exact promotion period / booking period / stay period supported by the source;
  6. minimum stay, meal plan, credits, complimentary nights, transfers, family benefits, blackout dates or other relevant conditions when confirmed;
  7. a concise Tiare View explaining why the offer is attractive and for which client profile.
- Do not invent dates, prices, availability, discounts, inclusions or restrictions. If a source does not state a period explicitly, say that the period must be confirmed rather than fabricating one.
- Current commercial terms should be checked against the hotel / airline / supplier source before publication.

## Flight-deal memory
- Deal Scout must search for worthwhile airfare specials alongside hotel specials.
- Search relevant premium and leisure routes, including business-class and premium-economy sales where they create meaningful value.
- Check airline direct offers plus reputable fare-search sources when available.
- Prefer offers that complement the hotel destinations selected in the same issue.
- For each airfare deal, record origin, destination, cabin, fare or discount, travel period, booking deadline, key restrictions and source.
- Do not include an airfare item merely because it is cheap; it must be genuinely attractive for a Tiare Travel client.
- If there are no worthwhile verified airfare specials, do not force an airfare page; state internally that none met the threshold.

These rules override arbitrary template defaults and should be applied automatically without asking the user to repeat them.
