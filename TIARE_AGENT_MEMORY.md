# Tiare Travel Agent Memory

Mandatory permanent rules for all Tiare Travel client-facing PDF work.

## Cover memory
1. The cover is full-bleed premium photography + typography only.
2. Never add decorative horizontal/vertical lines on the first page.
3. Never add grey lines.
4. Never add divider strokes, frames, borders, strips, panels or cards on the first page.
5. Never use partial overlay rectangles that create a visible edge/boundary across the cover.
6. If contrast is needed, use one uniform full-frame tonal overlay only.
7. Any reappearance of a previously rejected cover line is a QC failure and the file must be rebuilt before delivery.

## Tiare visual memory
- Quiet luxury, editorial, premium, image-led.
- No dashboard aesthetics, cheap cards, circles, UI chips, generic corporate layouts or technical-looking graphics.
- Bright, refined, high-quality hotel/destination photography; no watermarks.
- Large elegant typography, restrained copy, generous whitespace.
- Client-facing output only; no technical methodology or internal notes.
- Every PDF must be rendered and visually inspected before delivery.

These rules override arbitrary template defaults and should be applied automatically without asking the user to repeat them.
